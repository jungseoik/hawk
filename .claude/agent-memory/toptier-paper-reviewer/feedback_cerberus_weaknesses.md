원고 검토 시 우선 점검할 반복 패턴. 라운드별로 **해소/잔존**을 표기해 같은 지적을 반복하지 않는다.
코드 ground truth는 [[project-cerberus-code-facts]], 서지 검증은 [[reference-verified-bibliography]].

- CDS/BSI confound → Appendix C 이관 + 귀무 감산·ΔBSI. **해소**(1차)

- L_sim 정보이론 정당화 hand-wavy → §3.1.3 정보이론 단락 삭제됨. **해소**(3차)
- L_dis 잔여물 12개 지점 → 기여 제외 명시 + Appendix A 집중. **대체로 해소**(3차)
- 벤치마크 학습 오염(540/600) → heldout 471로 전면 교체, 학습분할과 **0건 중복** 실측. **해소**(3차)
- 언어 분할이 서로소가 아님(pobj 누출) → §3.4가 자인. **해소**(3차)
- "비디오 1회 판독" 오기 → §3.5가 2회로 정정. **해소**(3차)
- ego-motion 보정 → 실행 전 실측으로 기각하고 한계로 보고. **모범적 처리**(3차)

## 잔존 + 3차에서 새로 생긴 패턴 (2026-08-13)

**R3-1. 예측 두 개가 같은 도메인에서 반대를 가리키는데 가중 함수가 없다.**
H1(i) "이득 ∝ causal 비율"과 H1(ii) "마스크 퇴화 도메인에서 이득 감소"가 DoTA(causal 최고 43%,
마스크 최악 0.449)에서 정반대를 예측한다. 결합 함수가 사전 등록되지 않아 **DoTA는 어떤 값이
나와도 반증하지 못한다** — 그런데 DoTA가 평가의 62.8%, `flow↔duplicate` 처치 대비의 92%다.
→ 사전 등록 회귀(Δ_i ~ causal_i + mask_i + 교호작용)나 명시적 순위 예측으로 바꿀 것을 권고함.

**R3-2. 공변량 표의 분모가 공개되지 않는다.** §4.2 도메인 표의 causal 비율이 `normal` 클립을
분모에 포함한 값이다. 이상 클립으로 정규화하면 UBnormal 22%→38.9%, ShanghaiTech "0%(n=24)"→0/5.
**분모를 밝히지 않은 비율표는 이 논문의 반복 취약점**(구 스키마 150건 통계도 같은 문제).

**R3-3. 프로토콜을 교체하면 옛 프로토콜의 문장이 같은 절에 남는다.** §4.2 안에서
5범주 스키마(구)와 Appendix H.1의 4범주 스키마(신)가 공존하고, 벤치마크 본체 정의도
`context_dependent ∪ context_critical`(구) vs `causal`(신)로 충돌한다. §4.2 "주석자와 신뢰도"
단락은 폐기된 2단계 영상 절차와 존재하지 않는 "사람 간 κ"(주석자 1인)를 여전히 약속한다.
→ R2-2(철회 잔여물)와 같은 패턴의 재발. **프로토콜 교체 시 "본문 1단락 + 부록 전문" 2곳으로
제한하고 교체 전 문장을 전수 삭제**하도록 권고.

**R3-4. 사전 등록한 주 종점과 구현된 통계 절차가 어긋난다.** §4.8은 도메인별 값을 주 종점으로
사전 지정하나 §4.1과 `scripts/compare_arms.py`는 풀링 3대비에만 Holm을 적용한다(주 종점 무보정).
또 H7("차이 없으면 C1 불성립")이 §4.1의 음성결과 규칙("미검출로 보고")과 정면 충돌한다.
→ 동등성 마진(TOST) 사전 등록 권고.

**R3-5. 통제 실험이 도는 중에 통제 전제가 깨질 수 있다.** Stage-2 정류점 이탈(flow arm epoch 28)이
arm 특이적이면 4-arm이 서로 다른 실효 목적함수로 학습된다. 실측상 flow는 이탈 상태로 종료,
duplicate는 15 epoch까지 정류점. **arm별 이탈 시점 기록이 필수**.

**R3-6. 철회한 대비가 상위 지면에만 남는다(R2-1의 잔존).** §2.2는 "신호 공간 차이는 델타가
아니다"로 정정됐으나 **초록·§1.2·§3.1.1은 여전히 "플로우 이미지·RGB 차분과 근본적으로 구별"**을
판매한다. 지적할 때는 §2.2가 이미 정정했음을 인정한 뒤 상위 지면만 겨냥할 것.

**R3-7. 상호참조·수식 번호가 라운드마다 상한다(R2-4 지속).** 3차 실측:
§4.5의 "수식 9"(실제 10/11), Appendix D의 "수식 13"(존재하지 않음), Appendix B의 수식이
`(A.1)`로 붙음, **Appendix A.1 절이 Appendix I 말미에 물리적으로 위치**, H 번호 비단조.

## 유지·강화 권장 강점
- 원리 중심 reframing, 반증가능 가설 명시, 음성 결과의 정직한 보고, 사전 등록형 실패 시나리오.
- 실행 전에 효과를 측정해 실험을 기각한 것(ego-motion, 2일 절약)과 그 기록.
- κ 개선 후에도 "κ에서 정확도를 유도한 것은 오류"라고 자기 정정한 것 — 탑티어에서 실제 가점.
- 교란을 숨기지 않고 계측 arm(`flow_reinit`)으로 크기를 재기로 한 판단. 단 그 양이
  "(사전학습 입력 일치) + (L_BL 획득분)"의 합이라 **상한 해석과 C3 증거 해석이 충돌**한다는 점은
  아직 원고에 없다.
- `docs/review-log.md`에 "하지 않은 것 + 이유"를 남기는 방식.
