## 요청 형식의 특징 (3차)

지적 나열이 아니라 **판정**을 요구한다 — "이 논증이 대안 가설을 실제로 배제하는가,
반례를 만들어 시도해 보라", "이 결정이 방어 가능한가", "결과가 어떻게 나와도 쓸 수 있는가".
따라서 답은 (a) 반례 구성 → (b) 성립/불성립 판정 → (c) 성립시키는 최소 수정, 순서로 쓴다.
이미 처리된 항목(사용자가 "다시 지적 말라"고 명시한 것)은 **처리의 적절성만** 평가한다.

지적 우선순위: (1) 결과와 무관하게 지금 고쳐야 하는 자기모순·잔여물·오귀속,
(2) 결과 해석을 무효화할 설계 결함, (3) 구조·논지 사슬. 분량·문체는 마지막에 짧게.
