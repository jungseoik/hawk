각 라운드의 지적 → 조치 → 커밋을 잇는다. **하지 않기로 한 것도 이유와 함께 남긴다** —

## 옛 원고를 되가져오는 방법

원고 전체 이력은 git에 있다. 특정 시점의 문장을 찾으려면:

```bash
cd $CERBERUS_ROOT/hawk
git log --oneline --follow -- paper_translation/improved/01_introduction.md   # 변경 이력
git show <commit>:paper_translation/improved/01_introduction.md              # 그 시점 전문
git diff <commit> HEAD -- paper_translation/improved/                        # 무엇이 바뀌었나
```

### 하지 않은 것 (이유와 함께)

| 지적 | 왜 안 했나 |
|---|---|
| **문장 밀도 축소** (7,786 → 5,000~6,000) | 구조가 먼저이고, §4의 어느 부분이 지면을 벌었는지는 **결과를 보고서야** 정해진다. §5도 아직 자리를 차지하지 않았다. 결과 확보 후 수행 |
| **기여 5→3 재구성** | 4개까지 줄였다. 3개로 더 줄이려면 C3(언어 감독)를 C1에 흡수해야 하는데, C3는 이 연구의 실제 델타 중 하나이므로 결과를 보고 판단 |
| **ICML formal core 구축** (a) | 없는 이론을 붙이면 이론 없는 것보다 더 처벌받는다는 심사자 경고에 동의. 대신 C1을 예측으로 만들어 원리의 실체를 확보 |

### 심사자 판정 중 미해결로 남은 핵심 논점

> **ICML이 맞는 집인가.** `L_dis` 철회 후 formal core가 비었고, 유일한 수식 형태의 원리
> 진술(상보성 항등식)은 임의 마스크에 성립한다. 남은 실질은 입력 분해 + 브랜치 추가 +
> 언어 감독 + 자체 지표이며, 이는 CV 학회의 기여 형식이다. 일반성을 담보할 §4.7이 미구축.

이에 대한 현재 대응은 (i) C1을 예측으로 만들어 "정의"라는 지적을 무력화, (ii) §4.7에서
일반성을 주장 범위에서 제외, (iii) 4조건 통제를 C2로 승격하여 방법론 기여를 명시 — 세 가지다.
①의 결과가 나오면 이 논점을 재평가해야 한다.
