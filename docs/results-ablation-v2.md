# 절제 실험 v2 — 결과 (2026-08-23)

다섯 arm 전부 40 epoch 완주, held-out 470 클립 평가 완료. 이 문서는 **관측된 것만** 적는다.
해석과 원고 반영 방침은 아래 "무엇을 주장할 수 있나"에 분리해 둔다.

## 통제 조건

| 고정된 것 | 값 |
|---|---|
| 아키텍처·파라미터 수·토큰 수 | 전 arm 동일 |
| 표현 손실 가중치 | `CERBERUS_REPR_LOSS_WEIGHT=0` (전 arm) |
| effective batch / 샘플 | 4 / 10,000 per epoch |
| epoch | 40 |
| 평가 | 470 클립, `CUBLAS_WORKSPACE_CONFIG=:4096:8`, seed 고정 |

**arm 간 유일한 차이는 정적 스트림에 무엇이 들어가는가**(그리고 `flow_reinit` 은 정적 분기
가중치를 재초기화).

## ⚠ 먼저 — 집계 스크립트 버그를 고쳤다

`compare_arms.py` 가 arm 이름을 `config.static_ablation` 에서 뽑고 있었다. `flow_reinit` 의
정적 입력 모드도 `flow` 라 **딕셔너리 키가 충돌해 진짜 `flow` arm 이 조용히 덮어써졌다.**
5개 arm 을 한 번에 넣은 첫 실행의 숫자는 전부 `flow_reinit` 기준이었다.

고친 것: arm 이름을 run 디렉터리(`runs/abl2_<arm>/`)에서 뽑고, 이름이 중복되면 **중단**한다.
아래 숫자는 수정 후의 것이며, 4개 arm 만 넣었던 예비 실행과 일치한다.

## ⚠ 코퍼스 BLEU 를 쓰지 말 것 — 길이에 오염된다

`flow_reinit` 의 **코퍼스** BLEU-1 은 0.3412 로 전 arm 중 가장 높지만, **클립 단위** 평균은
0.3607 로 `flow`(0.3928)보다 **낮다.** 원인은 출력 길이다 — `flow_reinit` 의 출력 중앙값이
42 단어로 가장 길어(전체 36~37) 코퍼스 n-gram 집계가 부풀려진다.
**쌍 부트스트랩이 붙는 클립 단위 값만 쓴다.**

| 대비 | Scene recall Δ | clip-BLEU-1 Δ |
|---|---|---|
| flow_reinit − flow | +0.0293 [−0.007, +0.066] | −0.0321 [−0.044, −0.020] |
| flow_reinit − zero | −0.0173 [−0.054, +0.020] | −0.0304 [−0.042, −0.019] |
| flow_reinit − duplicate | +0.0517 [+0.010, +0.093] | +0.0023 [−0.011, +0.015] |

정적 분기를 **재초기화해도 성능이 떨어지지 않는다**(recall 은 오히려 `flow` 보다 위, CI 는 0 포함).
Stage-1 에서 정적 분기에 축적된 것이 하류에 실질적으로 쓰이지 않았다는 뜻이다.

## 무엇을 주장할 수 있나 / 없나

**없는 것 — 원래 주장하려던 것.**
CVD 분해가 기여라는 주장은 이 표본에서 지지되지 않는다. S2·S3 가 둘 다 null 이므로
`flow`·`random_mask`·`duplicate` 가 구분되지 않는다 — 정적 스트림에 **무엇이** 들어가는지가
성능을 바꾸지 않는다. `flow_reinit` 결과도 같은 방향이다.

**있는 것 — 관측된 것.**
1. 풀링에서 정적 스트림에 픽셀을 넣으면 `zero` 보다 **낮다**(S1 반대 방향, p=0.034).
2. 그 하락은 DoTA 에 몰려 있고(−0.117), 고정 카메라 ShanghaiTech 에서는 **부호가 뒤집힌다**(+0.282).
   풀링 값은 DoTA 가 437 중 290(66%)이라 사실상 DoTA 하나가 정한다 — 도메인별을 주 종점으로
   사전 지정해 둔 이유가 이것이다.
3. 정적 분기 가중치는 재초기화해도 무방하다.

**주의 — 2번을 "카메라 운동 때문"이라고 쓰면 사후 해석이다.** 도메인별 종점 자체는 사전
지정됐지만 "이동 vs 고정" 이라는 축은 결과를 보고 나서 고른 것이다. 쓰려면 관측으로만 적고,
검증은 별도 대비가 필요하다(예: DoTA 내부를 자체 카메라 운동량으로 층화 — 도메인 간 비교가
아니라 도메인 **내부** 비교라 데이터셋 차이와 교란되지 않는다).

또한 뒤집힌 쪽 표본이 작다 — ShanghaiTech n=21, UBnormal n=29. 단일 시드다.
